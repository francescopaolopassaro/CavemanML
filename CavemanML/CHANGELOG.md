# Changelog

## [1.0.0] - 2026-10-11

First release - the models of Synthelion 1.2.5 in pure C#.

### Added
- **SynthelionML** (`SynthelionMLCompressor`): learned per-token prompt compression - keep/drop scoring, rank-based ratio controller (70% target), `budget` and `minCompression` controls, always-keep set (structured values, numbers, URLs, e-mails, proper nouns, negations), per-sentence floor, CJK-aware join.
- **PrivacyGuardML** (`PrivacyGuardMLDetector`): learned PII confirmation (BIO tagging, 16 categories), implements `Caveman.PrivacyGuard`'s `IMlEntityDetector` so it plugs into `PrivacyAnalyzer.MlDetector`.
- **Pure-C# transformer engine** (`TinyEncoder`): `torch.nn.TransformerEncoderLayer` in eval mode - no torch, no onnxruntime, no native code. Verified against the PyTorch reference: probabilities and confidences agree to < 1e-3, tags, spans and compressed text are identical.
- **Weight readers** for safetensors and PyTorch `.bin` checkpoints (a minimal pickle VM; no Python needed).
- **Local model management** (`ModelManager`, `ModelStore`): install from Hugging Face into `~/.caveman/ml_models`, SHA-256 verification against the Hub's LFS digest, atomic writes, manifest with revision, `verify`, `CheckUpdateAsync`, `Remove`; `CAVEMAN_ML_MODELS_DIR`, per-model overrides, `HF_TOKEN`, shared `~/.synthelion/ml_models`.
- Tokenizer and char-n-gram hash (md5) bit-compatible with the training pipeline.

### Testing
- Parity tests against fixtures generated by `tools/make_reference.py` from the Python implementation; an explicit network suite exercises install / verify (including a corrupted weight file) / update check / remove against the real Hugging Face repositories.
